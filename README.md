# Civil Service Exam Practice

A Khmer-language practice website for candidates preparing for Cambodia's civil-service clerk exam.

## Pages

- `index.html` — study overview and suggested routine.
- `daily-quiz.html` — 20 selectable lessons with 120 practice questions, including new QCM based on the linked administration books and legal references. Scores and completed lessons are stored in the browser.
- `books.html` — book covers and embedded PDF readers, with links back to the source libraries.
- `past-papers.html` — past-paper references with clear official, unverified, and practice labels.
- The same page includes a learning library for commune/Sangkat administration books, laws and Prakas, summary lessons, and lesson-based QCM practice.
- `sang-sopheak-logo.jpg` — portrait logo used in the site header.

No build step is needed. Open `index.html` in a browser to use the site locally.

To publish with GitHub Pages, open the repository's **Settings → Pages**, choose **Deploy from a branch**, then select `main` and `/ (root)`.

The quiz questions are practice material, not official exam questions. The Telegram exam PDF is marked unverified; the Ministry notice is a candidate/room list, not an exam paper. Check current exam requirements and dates with the Ministry of Civil Service.
